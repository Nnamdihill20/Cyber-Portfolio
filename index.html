TypeScript / React Jan 2026

Honeypot Attack Monitor

A real-time dashboard for visualizing attacks captured by a honeypot. It classifies incoming traffic against ten attack patterns — brute force, SQL injection, port scanning, command injection, and others — across eight commonly-targeted services (SSH, Telnet, RDP, SMB, and more), then charts the results as a live feed, a timeline, a port-distribution view, and a geographic breakdown of attack origins.

TypeScript / React Jan 2026

Secure Messaging App

A working demonstration of end-to-end encrypted messaging: ECDH (P-256) key exchange so two parties derive a shared secret without ever transmitting it, HKDF for per-message key derivation, and AES-256-GCM for authenticated encryption. Each message advances a ratchet counter, so a single compromised key can't be used to decrypt earlier messages — the same forward-secrecy principle behind protocols like Signal's.

Python / Flask Sep 2025

Web Application Firewall (Lite)

A lightweight WAF that sits in front of a backend and inspects every incoming request for SQL injection, cross-site scripting, and path traversal patterns before deciding whether to block or forward it. Every request — allowed or blocked — is logged with a clear reason, so the filtering decisions stay auditable rather than opaque.

Python Sep 2025

Password Manager

A command-line password manager that derives its encryption key from a single master password using PBKDF2-HMAC (SHA-256), then encrypts every stored credential with Fernet symmetric encryption. Nothing is stored in plaintext — the master password never touches disk, only the key it derives.

Python / Scapy Sep 2025

Network Sniffer Tool

A live packet sniffer built on Scapy that captures traffic off a network interface, filters it by protocol (ICMP, DNS, HTTP, TCP, UDP), and checks source addresses against a blacklist to flag suspicious IPs. Captures export to standard PCAP files, so anything caught here can be handed straight to Wireshark for deeper analysis.
